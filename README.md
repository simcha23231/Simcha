# 🎰 קזינו ההומור - אימון הומור יומיומי ממכר 🎰

אפליקציית אימון הומור אינטראקטיבית בעברית שהופכת אותך לגאון קומי דרך תרגילים יומיומיים מהנים ומתגמלים!

## ✨ תכונות עיקריות

### 🎲 4 סוגי תרגילים
- **היפרבולה (💥)** - הפוך דברים יומיומיים למוגזמים ומטורפים
- **השוואות מוזרות (🔄)** - השווה דברים לא קשורים בצורה מפתיעה
- **What If (🤔)** - שנה מצבים רגילים לתרחישים אבסורדיים
- **תצפיות (👁️)** - מצא את המצחיק במצבים יומיומיים

### 🎮 גיימיפיקציה מלאה
- **מערכת נקודות ורמות** - עלה ב-50+ רמות מ"טירון ההומור" ל"אלוהות ההומור"
- **סטריקים (רצפים)** - שמור על רצף יומי וקבל בונוסים
- **באדג'ים והישגים** - פתח 8+ באדג'ים מיוחדים
- **משוב מילולי מטורף** - 20+ תגובות מעודדות שונות

### 🎨 עיצוב קזינו מרהיב
- צבעים: זהב, סגול, אדום, ניאון
- אנימציות מטורפות: confetti, ברקים, נצנוצים
- גופנים דרמטיים ומרגשים
- אפקטים ויזואליים מלאי אנרגיה

### 📱 PWA מלא
- עובד בדפדפן ואפשר להוסיף למסך הבית
- Responsive - מושלם במובייל ובדסקטופ
- שמירה מקומית עם LocalStorage
- תמיכה מלאה ב-RTL

## 🚀 איך להתחיל?

1. פתח את `index.html` בדפדפן
2. זהו! האפליקציה מוכנה לשימוש
3. (אופציונלי) הוסף למסך הבית לחוויה כמו אפליקציה

## 🎯 איך זה עובד?

1. **התרגיל היומי** - כל יום האפליקציה בוחרת אקראית תרגיל חדש
2. **כתוב תשובה** - השתמש בקופסת הכתיבה לכתוב את התשובה שלך
3. **קבל משוב מטורף** - האפליקציה מגיבה עם חגיגה ויזואלית ומשוב מעודד
4. **צבור נקודות ועלה רמות** - כל תרגיל נותן נקודות + בונוסים לסטריקים
5. **שמור על הרצף** - תעשה תרגיל כל יום כדי לשמור על הסטריק!

## 🛠️ טכנולוגיות

- HTML5
- CSS3 (אנימציות, גרדיאנטים, RTL)
- Vanilla JavaScript (ES6+)
- LocalStorage לשמירת נתונים
- Canvas API לאפקטי confetti
- PWA (Progressive Web App)

## 📱 מסכים

1. **דשבורד** - מסך הבית עם התרגיל היומי וסטטיסטיקות
2. **תרגיל** - מסך ביצוע התרגיל עם תיבת כתיבה
3. **משוב** - מסך המשוב עם חגיגה ואנימציות
4. **היסטוריה** - כל התרגילים שהשלמת
5. **סטטיסטיקות** - מידע מפורט על ההתקדמות
6. **הגדרות** - שינוי שם, תזכורות, איפוס

## 🎨 עיצוב

האפליקציה מעוצבת בסגנון **קזינו דיגיטלי**:
- רקע כהה עם גרדיאנטים סגול-שחור
